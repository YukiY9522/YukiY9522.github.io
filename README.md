# ポートフォリオ公開サイト

HTML、CSS、JavaScriptを用いて制作するポートフォリオサイトです。

Webサイトの制作に加え、Git・GitHubによるバージョン管理や、GitHub Flowを用いた開発手法の習得を目的としています。

## 公開サイト

**URL：** [https://YukiY9522.github.io/](https://polyfortrain.github.io/)

GitHub Pagesを利用して公開しています。

## 使用技術・開発環境
- フロントエンド...HTML5,CSS3,JavaScript
- 開発環境...Eclipse IDE
- バージョン管理...Git/GitHub
- 開発フロー ...GitHub Flow
- ホスティング ...GitHub Pages

##開発・バージョン管理
開発にはGitHub Flowを採用しています

バージョン番号は[Semeantiv Versioning](https://semver.org/lang/ja/)を参考に管理し、
リリース時にはGitタグとGitHub Releaseを利用します。
